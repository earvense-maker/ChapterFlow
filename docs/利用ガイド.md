# ChapterFlow 利用ガイド

## ChapterFlow とは

ChapterFlow — API-Powered Narrative Studio は、自分のAPIキーで連載小説とロールプレイを続けるWindowsアプリです。
作品設定、これまでの流れ、設定草案をもとに、LLM APIを使って次の話を生成できます。
作品データの保存先はPC内です。生成や相談を実行するときは、選択したLLM事業者のAPIへ必要な内容を送信します。

## 必要なもの

- 64bit版の Windows 10 または Windows 11
- Gemini、DeepSeek、OpenAI、xAI、OpenRouter のいずれかの API キー

初回ベータではGemini、DeepSeek、xAIを実機確認済みです。OpenAIとOpenRouterは実装と自動テストを確認済みですが、実APIでは未検証です。

インストーラ版とポータブル版は、どちらも利用者側で Node.js をインストールする必要はありません。

## インストールと起動

### インストーラ版

1. `ChapterFlow Setup <version>.exe` を実行します。
2. SmartScreen の警告が出た場合は「詳細情報」から「実行」を選びます。
3. インストール完了後、ChapterFlow が起動します。

通常はこちらを使ってください。スタートメニューや Windows のアプリ一覧から起動・アンインストールできます。


### ポータブル版

1. `ChapterFlow <version>.exe` を、デスクトップや `Documents` などのローカルフォルダに置きます。
2. exe をダブルクリックして起動します。

インストールせずに使いたい場合はこちらを使ってください。新規環境では、ポータブル版も作品データは exe の横ではなく `Documents\ChapterFlow` に保存されるため、インストーラ版と同じデータを参照します。

## API キーの取得と登録

### 初めての方へ（おすすめの始め方）

まずは **Gemini の API キーで、モデルは `gemini-3.6-flash`** から始めるのが最も手軽です。Google AI Studio では Gemini API に無料枠が用意されており、`gemini-3.6-flash` はこの無料枠の対象で、個人利用の範囲であれば無料のまま試せることが多いです。

- Google アカウントでログインして、API キーを1つ発行するだけで始められます。
- 具体的な無料枠の回数上限・条件は Google 側で予告なく変わるため、最新の内容は [Gemini API pricing](https://ai.google.dev/pricing) を確認してください。
- 使い心地を試したうえで、より重厚な文章や別モデルを試したくなったら、DeepSeek や OpenAI、xAI などに切り替えられます。

### 各社のキー発行ページ

いずれか1つ以上の API キーを用意してください。

- Gemini: [Google AI Studio API keys](https://aistudio.google.com/app/apikey) に Google アカウントでログインし、API キーを作成します。
- DeepSeek: [DeepSeek API Keys](https://platform.deepseek.com/api_keys) にログインし、API キーを作成します。
- OpenAI: [OpenAI API Keys](https://platform.openai.com/api-keys) にログインし、API キーを作成します。
- xAI: [xAI Console](https://console.x.ai/) にログインし、API キーを作成します。
- OpenRouter: [OpenRouter Keys](https://openrouter.ai/settings/keys) にログインし、APIキーを作成します。既定モデルは無料の `google/gemma-4-31b-it:free` です。無料モデルは通常20回/分・50回/日の制限があり、混雑や提供状況によって利用できない場合があります。その場合は作品の技術設定で別のモデル名へ変更してください。

作成した API キーは、アプリ内の「アプリ設定」から登録します。

**生成はあなた自身のAPIキーで行われ、利用量に応じて各社から課金されます。利用前に各社の料金ページと上限設定を確認してください。**

## データ送信とプライバシー

- 作品データはPC内に保存され、ChapterFlow独自のクラウドへは保存されません。
- 生成、相談、接続確認を実行すると、作品設定、本文、会話履歴、入力した指示のうち処理に必要な部分が、選択したLLM事業者へ送信されます。
- OpenRouterを選んだ場合、生成内容はOpenRouterと、実際に選択されたモデルの提供事業者の双方へ送信されます。`openrouter/free`では呼び出しごとに提供事業者が変わる場合があります。利用前に[OpenRouterのPrivacy設定](https://openrouter.ai/settings/privacy)と、許可するデータポリシーを確認してください。
- 送信後のデータの取り扱いは、各LLM事業者の利用規約とプライバシーポリシーに従います。
- APIキーはデータ保存先の `config\credentials.json` に平文で保存され、認証のため選択したLLM事業者へ送信されます。
- ChapterFlowには、作者独自のアクセス解析やテレメトリー送信はありません。

## データの保存場所とバックアップ

作品データと設定は `Documents\ChapterFlow` に保存されます。バックアップするときは、このフォルダを外付けドライブやクラウドストレージへコピーしてください。

Electron 版の「設定」では、現在のデータをコピーして新しい場所へ運ぶ「保存先を移動」と、すでに作品が入っている別の ChapterFlow フォルダをそのまま使う「既存の保存先に切り替える」を選べます。切り替えでは現在のデータはコピーも削除もされません。選択先の作品データと `config` 内の API キー設定が使われるため、プレビューに表示された作品を確認してから実行してください。同じ保存先を複数のPCやアプリから同時に使用しないでください。

以前の Yumeweaving に保存したデータを引き継ぐ場合は、退避したデータを `Documents\ChapterFlow` へ移してからChapterFlowを起動してください。

API キーはデータ保存先の `config\credentials.json` に平文で保存されます。バックアップや相談のためにフォルダを人へ渡す場合は、`config` フォルダを除いてください。

インストーラ版をアンインストールしたり、ポータブル版の exe を削除したりしても、データ保存先を削除しない限り作品データは残ります。

## 一文から作品を始める（クイックセットアップ）

新しく作品を作るとき、詳細な設定を入力しなくても、**見たい作品を一文書くだけ**で始められます。

1. トップ画面の「一文から始める」を選びます。
2. 「見たい作品・関係・感情」に希望を書きます。
3. 必要なら「絶対に守ってほしいこと」と「最初に見たい場面」を追加します。
4. 「この一文で作品を作る」を押すと、アプリが必要な最小の人物・舞台・未公開設定を補完します。
5. 補完した「作品の約束（hard候補）」が確認カードで表示されるので、残したいものを選んで「この内容で作品を作る」を押します。

詳細にこだわりたい場合は、いつでも「詳細を自分で決める」から従来の設定相談に切り替えられます。相談中に作った内容は引き継がれます。

## 作品の約束

作品設定の先頭にある「作品の約束」は、**この作品が守るべき条件**です。2種類あります。

- **強く守る（hard・最大8件）**: 「護衛は最後まで裏切らない」のような約束・禁止。本文生成のたびに必ずプロンプトへ載り、予算で切り詰められません。
- **好み（soft・最大12件）**: 「冷たく静かな雰囲気」のような方向性。プロンプト上の優先度は low で、縮小されることがあります。

### 約束の確認方法

- 約束を編集すると、意味的に両立しない組み合わせが検出された場合、確認画面が表示されます。内容を承知して保存するか、文言を調整してください。
- 「文言単位の禁止」は従来どおり NG表現に登録してください。作品の約束とNG表現は別の機能です。

### 検証モード（strict / fast）

hard契約がある作品では、生成後に本文が約束を守っているかを検証します。

- **strict（既定）**: 本文の生成が終わってから検証・必要な場合は1回だけ修復し、問題がなければ本文を表示します。ストリーミング表示の代わりに「本文を生成中 → 作品の約束を確認中 → 修復中 → 再確認中」の進捗が表示されます。
- **fast**: ストリーミング表示を優先します。検証は完了後に行われ、違反を含む可能性のある本文が一瞬表示されることがあります。

検証に失敗した場合は、本文が「確認が必要」の状態で保存されます。再生成・問題箇所の確認・そのまま表示のいずれかを選べます。警告を無視して採用しても、作品の約束自体は自動で変わりません。

## 未公開設定（潜在設定）

アプリが補完した設定のうち、**本文にまだ現れていないものは「未公開設定」**として作品設定に並びます。本文で明らかになるまでは、既定で件数とカテゴリだけが表示され、内容は隠されます。

- 内容を見るには「内容を見る」を押します。「先の展開に関する内容が含まれます」と表示されます。
- 未公開設定は本文に現れるまで自由に差し替えられます。本文で明らかになったものは「公開済みの設定」へ移ります。
- 「固定」した項目は、作者の明示操作でない限り自動で変更・整理されません。
- 「退役」させた項目は以後の生成で使われません（削除ではなく記録として残ります）。

### 採用と正史

小説では、**「採用」した本文だけ**が設定の正史になります。ドラフトの時点では未公開設定は変わりません。

- 採用された本文から、事実・主張・噂・示唆が自動で抽出され、未公開設定の状態や公開済み設定が更新されます。
- 台詞や噂は「誰かが言った」という事実として記録され、客観的な事実（fact）には自動でなりません。
- 「採用を取り消す」と、その場面だけを根拠にしていた設定は未公開状態へ戻ります。別の場面や手動編集が根拠に残っている場合は維持されます。

### 要確認（競合）

採用した本文が作品の約束や公開済み設定と矛盾している可能性がある場合、Reader上部と作品設定に「要確認」が表示されます。

- 「今回の本文だけ例外として残す」: その採用場面だけを承認済み例外として残します（約束自体は変わりません）。
- 「誤検出として解決済みにする」: 競合を解決済みにします。
- 「表示を閉じる」: 表示だけを抑えます。次回生成前の要確認一覧には残ります。

## ロールプレイのセッション設定

ロールプレイの会話は、**会話を始めた時点の作品設定をスナップショット**して進行します。会話の途中で作品設定を変えても、進行中の会話には反映されません。新しい会話を始めると最新の設定が使われます。設定が変わった場合は、会話一覧に「設定が変更されました」と表示されます。

会話中にキャラクターが明かした設定は、そのセッションの中だけの記録として残ります。作品設定へ残したい場合は、セッションの設定詳細から1件ずつ明示的に「作品設定へ残す」を選んでください。選ばない限り、別のセッションや小説には持ち込まれません。

## データ送信と保存についての注意（未公開設定）

- 未公開設定は**ネタバレ防止のための表示設定**であり、外部からのアクセスを防ぐ仕組みではありません。ローカルアプリなので、あなたのPCにアクセスできる人は設定画面の操作で内容を見られます。
- 生成・検証・相談を実行すると、未公開設定を含む必要な作品情報が**選択したLLM事業者へ送信**されます。
- 生成のたびに、プロンプトの内容が保存先の `generations\<generationId>.prompt.txt` へ保存されます。未公開設定がプロンプトに載った場合、**このファイルにも未公開設定が含まれます**。
- 作品フォルダを人に渡す・共有する・バックアップを共有するときは、`generations` フォルダに未公開設定が含まれ得ることを確認してください。
- 開発用の診断ログやクラッシュログにも未公開設定が含まれる可能性があります。不具合報告へ添付する前に内容を確認してください。

## トラブルシューティング

### SmartScreen の警告が出る

初回配布ではコード署名を行わないため、Windows が警告を出すことがあります。入手元が正しいことを確認したうえで、「詳細情報」から「実行」を選んでください。

### アプリがすでに起動している

ChapterFlow を二重起動した場合、新しいウィンドウは開かず、既存のウィンドウが前面に表示されます。反応しない場合は、タスクマネージャーで ChapterFlow を終了してから起動し直してください。

### データが見当たらない

インストーラ版とポータブル版は同じデータ保存先を参照します。アプリ内で保存場所を変更した場合は、「設定」内のデータ保存場所を確認してください。

### 起動できない

PCを再起動してからもう一度起動してください。それでも起動しない場合は、表示されたエラーメッセージと、使っている配布物がインストーラ版かポータブル版かを控えてください。未処理のエラーで終了した場合は、データ保存先の `logs\crash.log` に原因調査用の記録が残ることがあります。

`crash.log` は代表的なAPIキー形式を自動的に伏せますが、作品名、PC内のパス、外部サービスの応答などが含まれる可能性があります。問い合わせへ添付する前に内容を確認し、APIキー、公開したくない本文、個人情報を削除してください。
