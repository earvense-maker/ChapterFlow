# ChapterFlow 0.1.0-beta.12

> これは過去版です。通常は[beta.13](https://github.com/earvense-maker/ChapterFlow/releases/tag/v0.1.0-beta.13)を利用してください。

人物設定の「見せない面」を廃止し、ロールプレイで会話中に明かされた設定の公開状態を、次のターンから反映するようになった公開ベータ第12版です。

> [!IMPORTANT]
> このアプリはコード署名を行っていないため、初回起動時にWindows SmartScreenの「WindowsによってPCが保護されました」という警告が表示されることがあります。公式リリースから入手し、必要に応じて `SHA256SUMS.txt` と照合したものだけを、「詳細情報」→「実行」で起動してください。

## beta.12の主な変更

- 人物設定の「見せない面」を廃止しました。人物の内面・普段表に出にくい性質は「概要」または「特徴」で表現し、公開時期を管理したい設定は作品設定の「未公開設定」へ入力してください。
- 設定づくり（設定相談・クイックセットアップ・人物編集・AI相談）と、小説・ロールプレイの生成プロンプトから「見せない面」を削除しました。
- ロールプレイで会話中に明かされた設定を、要約と同じタイミングでセッション内の記録として保存し、次のターンのプロンプトへ反映するようになりました。会話ですでに知られた事実を「まだ知らない」前提で演じ続けません。
- 会話開始時点の未公開設定（初期canon）が会話中に公開された場合、次のターンから「この会話で公開済み」として扱われます。「未公開」と「公開済み」が同時にプロンプトへ出ません。
- バックグラウンドの会話要約でも、要約本文・関係性・セッション内設定の記録が同じ時点まで保存されるようになりました。要約の構造化結果にセッション内設定の配列が含まれない場合は、要約自体が失敗扱いになり、中途半端に記憶が進みません。

## 既存作品について（重要）

- **既存の「見せない面」データは自動で移行されません。** 旧データに残った内容は読み込み時に無視され、人物設定を次に保存した時点で自然に消えます。内容を残したい場合は、「概要」または「特徴」への転記、公開時期を管理したい場合は「未公開設定」への登録を手動で行ってください。
- 既存のロールプレイセッションも従来どおり開けます。会話中に公開済みの設定は、これまでどおり要約とセッション内の記録で引き継がれます。

## 追加のモデル利用について

- ロールプレイの会話要約: 従来と同じ要約の1回の呼び出しで、セッション内の設定記録も同時に行います。メッセージ1件ごとの追加呼び出しはありません。
- 要約・記憶の再構築の回数自体は変更していません。

## 利用前に確認してください

- 更新前には作品フォルダを別の場所へバックアップしてください。
- 未公開設定は、生成・検証・相談のたびに必要な範囲で選択したAI事業者へ送信されます。
- 生成のたびに保存される `generations\<generationId>.prompt.txt` には、プロンプトに載った未公開設定が含まれます。作品フォルダを共有・バックアップするときは `generations` フォルダの内容を確認してください。
- 診断ログや `logs\crash.log` にも未公開設定が含まれる可能性があります。不具合報告へ添付する前に内容を確認してください。
- APIキーはPC内の `config\credentials.json` に平文で保存されます。共有PCでの利用やファイル共有に注意してください。
- ベータ期間中はデータ形式や画面を変更する可能性があります。不具合報告にAPIキーや公開したくない本文を添付しないでください。

詳しい操作手順は配布物に同梱した `ChapterFlow-UserGuide-ja.md` を参照してください。
