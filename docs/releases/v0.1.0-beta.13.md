# ChapterFlow 0.1.0-beta.13

妄想増幅器と明晰夢モードを追加し、連載小説・ロールプレイの編集、設定整合性、長期継続を強化した公開ベータ第13版です。

> [!IMPORTANT]
> このアプリはコード署名を行っていないため、初回起動時にWindows SmartScreenの「WindowsによってPCが保護されました」という警告が表示されることがあります。公式リリースから入手し、必要に応じて `SHA256SUMS.txt` と照合したものだけを、「詳細情報」→「実行」で起動してください。

## beta.13の主な変更

- **妄想増幅器**を追加しました。小説またはロールプレイの場面後に3〜5件の方向候補を提示し、候補選択、自由記述、「この場面に留まる」、「別の方向を出す」から続きを進められます。
- 妄想増幅器では、場面全体や選択した一節を「ここ好き」として記録できます。作品内と作品横断の暫定的な好みの仮説は、設定画面で閲覧・訂正・削除でき、グローバル学習もオフにできます。
- **明晰夢モード**を追加しました。本文と一行入力を中心に、入力した言葉または空Enterによる観察で夢世界を進められます。夢をまたぐ生の記憶は、閲覧・書き出し・一時停止・全消去できます。
- 小説本文とロールプレイの発言を直接編集し、版履歴から以前の内容へ復元できるようになりました。採用済み本文の編集後は、物語状態と未公開設定を編集後の本文から再抽出します。
- ロールプレイで会話中に明かされた設定、要約、関係性の保存タイミングを揃え、次のターンへ一貫して反映するようにしました。要約結果が不完全な場合は中途半端に記憶を進めません。
- 作品設定のAI相談を独立したワークスペースへ整理し、設定横断の気づき、相談、変更候補、生成後の自動レビュー履歴を確認しやすくしました。
- Xiaomi MiMoをモデルプロバイダーへ追加しました。従量課金の `sk-` 形式キーと `mimo-v2.5` / `mimo-v2.5-pro` に対応します。
- モデルへ送るプロンプトの予算管理、長期文脈の要約、JSON形式タスクの出力制御、DeepSeekの思考出力処理を強化しました。
- 現行機能、主要な上限値、データ送信範囲、リリース確認項目をまとめたHTML説明書を配布物へ追加しました。

## 既存作品について

- 既存作品は `standard` モードとして従来どおり開きます。妄想増幅器や明晰夢へ自動変換されません。
- 作品形式（小説／ロールプレイ）と体験モードは、作品作成後に切り替える仕様ではありません。新しい体験を使う場合は、トップ画面の専用入口から作品を作成してください。
- beta.12以前の「見せない面」データは引き続き読み込み時に無視されます。残したい内容は「概要」「特徴」または「未公開設定」へ手動で移してください。
- 更新前に `Documents\ChapterFlow` または現在設定している保存先を別の場所へバックアップしてください。

## 追加のモデル利用について

- 妄想増幅器の方向候補は、本文またはキャラクター応答とは別のモデル呼び出しで生成します。
- 明晰夢は通常のロールプレイと同様に、ターンごとの応答と一定量ごとの要約でモデルを使用します。
- 生成後の設定レビュー、NG表現の自動書き換え、文体変調の構成分析を有効にすると、設定に応じて追加のモデル呼び出しが発生します。
- API利用料金は利用者負担です。モデル名、料金、無料枠、提供状況は各事業者側で変更される場合があります。

## データとプライバシー

- 生成・相談・検証では、必要な作品設定、本文、会話履歴、未公開設定、入力した指示が選択中のAI事業者へ送信されます。
- 妄想増幅器では、関連する暫定的な好みの仮説が生成材料として送信されることがあります。
- 明晰夢では、過去に入力した言葉とその直前の夢本文が、将来の夢の残響として送信されることがあります。記録と送信はアプリ設定から一時停止できます。
- APIキーはPC内の `config\credentials.json` に平文保存されます。作品データやバックアップを人へ渡す場合は `config` を除外してください。
- `generations\*.prompt.txt`、開発診断ログ、`logs\crash.log` には未公開設定や本文が含まれる可能性があります。共有前に内容を確認してください。
- OpenRouterでは、OpenRouterと実際のモデル提供事業者の双方へ内容が送信されます。利用前にOpenRouterのPrivacy設定を確認してください。

詳しい操作と現行仕様は、配布物に同梱した `ChapterFlow-UserGuide-ja.md` と `ChapterFlow-Current-Spec-ja.html` を参照してください。
