# ChapterFlow 0.1.0-beta.11

「作品の約束」と「未公開設定」を導入した公開ベータ第11版です。一文の希望から作品を始められ、アプリが補完した設定は本文で明らかになるまで自由に差し替えられるようになりました。

> [!IMPORTANT]
> このアプリはコード署名を行っていないため、初回起動時にWindows SmartScreenの「WindowsによってPCが保護されました」という警告が表示されることがあります。公式リリースから入手し、必要に応じて `SHA256SUMS.txt` と照合したものだけを、「詳細情報」→「実行」で起動してください。

## ダウンロード

- [`ChapterFlow.Setup.0.1.0-beta.11.exe`](https://github.com/earvense-maker/ChapterFlow/releases/download/v0.1.0-beta.11/ChapterFlow.Setup.0.1.0-beta.11.exe): 通常はこちら（インストーラ版）
- [`ChapterFlow.0.1.0-beta.11.exe`](https://github.com/earvense-maker/ChapterFlow/releases/download/v0.1.0-beta.11/ChapterFlow.0.1.0-beta.11.exe): インストールせずに使うポータブル版
- [`SHA256SUMS.txt`](https://github.com/earvense-maker/ChapterFlow/releases/download/v0.1.0-beta.11/SHA256SUMS.txt): 上記exeのSHA-256確認用

対応環境は64bit版Windows 10 / 11です。自動アップデートはないため、新版はGitHub Releasesから手動で入手してください。

## beta.11の主な変更

- トップ画面に「一文から始める」を追加しました。見たい作品を一文書くだけで、アプリが必要な最小の人物・舞台・未公開設定を補完して作品を作れます。
- 作品設定に「作品の約束」を追加しました。強く守る約束（hard・最大8件）と好み（soft・最大12件）を分けて管理し、hard契約は生成プロンプトで常に最優先されます。
- 生成後の本文がhard契約と意味的に矛盾していないかを検証するようになりました。strictモード（既定）でも本文は生成された部分から表示し、必要なら1回だけ修復して確定本文へ置き換えます。
- アプリが補完した「未公開設定」を、本文に現れるまで内容を隠して管理できるようになりました。採用した本文から明らかになった設定は「公開済みの設定」へ自動で移ります。
- 採用した本文から事実・主張・噂・示唆を抽出する方式を刷新しました。台詞や噂は客観的事実へ自動昇格しません。
- 採用した本文が約束や公開済み設定と矛盾した場合、Readerと作品設定に「要確認」を表示し、解決操作を選べるようになりました。
- ロールプレイの会話中に明かされた設定を、セッション内の記録として保存し、「作品設定へ残す」で1件ずつ作品へ昇格できるようになりました。
- ロールプレイの会話は開始時点の契約・未公開設定をスナップショットして進行し、会話の途中で設定を変えても進行中の会話は変わりません。

## 既存作品について（重要）

- **既存の作品は自動で移行されません。** 作品の約束・未公開設定が無い状態のまま、従来どおり動きます。
- 未公開設定や「作品の約束をAIで抽出」を追加する場合は、作品設定から手動で行ってください。
- 作品を複製すると、作品の約束だけが引き継がれます。未公開設定の台帳は複製されず、複製先では空の状態から再補完されます。

## 追加のモデル利用について

- クイックセットアップの計画作成: 1回のモデル呼び出し。
- hard契約がある本文生成: 検証に最大+1回、違反時の修復に+1回、再検証に+1回の追加モデル呼び出しが発生します（最大+3回）。
- 採用後の状態抽出: 従来の物語状態抽出と同じ1回の呼び出しで、未公開設定の抽出も同時に行います（追加呼び出しはありません）。
- ロールプレイの会話要約: 従来の要約と同じ呼び出しで、セッション内の設定記録も同時に行います。メッセージ1件ごとの追加呼び出しはありません。
- これらは設定から無効化したり、fastモードで表示を優先したりできます。API利用料金は利用者負担です。

## 利用前に確認してください

- 更新前には作品フォルダを別の場所へバックアップしてください。
- **未公開設定は、生成・検証・相談のたびに必要な範囲で選択したAI事業者へ送信されます。**
- 生成のたびに保存される `generations\<generationId>.prompt.txt` には、プロンプトに載った未公開設定が含まれます。作品フォルダを共有・バックアップするときは `generations` フォルダの内容を確認してください。
- 診断ログや `logs\crash.log` にも未公開設定が含まれる可能性があります。不具合報告へ添付する前に内容を確認してください。
- APIキーはPC内の `config\credentials.json` に平文で保存されます。共有PCでの利用やファイル共有に注意してください。
- ベータ期間中はデータ形式や画面を変更する可能性があります。不具合報告にAPIキーや公開したくない本文を添付しないでください。

詳しい操作手順は配布物に同梱した `ChapterFlow-UserGuide-ja.md` を参照してください。
