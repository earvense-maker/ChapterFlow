# ChapterFlow 0.1.0-beta.9

生成後の本文からNG表現を見つけ、該当箇所だけを確認・書き換えできるようにした公開ベータ第9版です。通知音とエラー時の復旧表示も改善しました。

<img src="https://github.com/earvense-maker/ChapterFlow/releases/download/v0.1.0-beta.9/chapterflow-introduction.png" alt="ChapterFlow — AIで自分用の小説とロールプレイを作るアプリ" width="50%">

> [!IMPORTANT]
> このアプリはコード署名を行っていないため、初回起動時にWindows SmartScreenの「WindowsによってPCが保護されました」という警告が表示されることがあります。公式リリースから入手し、必要に応じて `SHA256SUMS.txt` と照合したものだけを、「詳細情報」→「実行」で起動してください。

- [`ChapterFlow.Setup.0.1.0-beta.9.exe`](https://github.com/earvense-maker/ChapterFlow/releases/download/v0.1.0-beta.9/ChapterFlow.Setup.0.1.0-beta.9.exe): 通常はこちら（インストーラ版）
- [`ChapterFlow.0.1.0-beta.9.exe`](https://github.com/earvense-maker/ChapterFlow/releases/download/v0.1.0-beta.9/ChapterFlow.0.1.0-beta.9.exe): インストールせずに使うポータブル版

対応環境は64bit版Windows 10 / 11です。自動アップデートはないため、新版はGitHub Releasesから手動で入手してください。

## beta.9の主な変更

- 作品別・共通のNG表現を、生成プロンプトへ載せる方式から、生成後の本文で検出する方式へ変更しました。過去の本文にも登録内容が反映され、該当箇所がハイライトされます。
- ハイライトされたNG表現を含む一文だけをモデルで書き換えられるようになりました。本文全体は作り直しません。
- 生成完了後にNG表現を古い順から自動で書き換える設定を追加しました。1回の生成につき1〜10件の上限を指定でき、書き換えられなかった箇所はハイライトのまま残ります。
- 生成通知の設定を作品の生成設定からも変更できるようにし、複数の通知音から選択できるようになりました。
- 「書き直す」を開いたとき、現在表示している案を作った指示を引き継ぐようにしました。案を切り替えた場合も、その案の指示が表示されます。
- 画面の描画で予期しないエラーが起きたとき、白い画面のままにならず、再読み込みや設定画面へ移動できるエラー表示を追加しました。
- サーバーやアプリ本体が未処理の例外で終了した場合、原因調査用の記録を保存先の `logs\crash.log` へ残すようにしました。保存先へ書けない場合はWindowsの一時フォルダへ記録します。
- 起動処理、パッケージ内容の検証、状態・認証情報・保存処理の回帰テストを強化しました。

## 追加のモデル利用について

- NG表現の手動書き換えは、実行するたびに該当する一文をモデルへ送信します。
- NG表現の自動書き換えを有効にした場合、設定した上限まで、1件につき1回の追加モデル呼び出しが発生します。
- 自動設定レビューや文体解析を有効にしている場合は、従来どおり本文生成とは別のモデル呼び出しが発生することがあります。
- これらは設定から無効化できます。API利用料金は利用者負担です。

## 利用前に確認してください

- 更新前には作品フォルダを別の場所へバックアップしてください。
- APIキーはPC内の `config\credentials.json` に平文で保存されます。共有PCでの利用やファイル共有に注意してください。
- 生成・相談・書き換え・自動レビュー・文体解析時には必要な作品情報が選択したAI事業者へ送信されます。各社の最新の料金とデータ利用条件を確認してください。
- NG表現の自動書き換えは生成直後の本文を変更します。通知とハイライトを確認し、意図に合わない場合は手動で修正してください。
- `logs\crash.log` を不具合報告へ添付する場合は、作品名、PC内のパス、外部サービスの応答など公開したくない情報が含まれていないか確認してください。
- ベータ期間中はデータ形式や画面を変更する可能性があります。不具合報告にAPIキーや公開したくない本文を添付しないでください。
